# v0.51.0 release evidence — 2026-11-06

## Delivered scope

Experimental `mcpm review-artifacts` compares two explicit uncompressed canonical
USTAR snapshots using dated Agent Skills or Claude plugin declaration profiles.
It binds changed content/modes, components, literal references and coverage gaps
to retained bytes. It does not extract, install or execute artifacts, invoke
native validators or contact the network. Host activation and safety stay unknown.
See the [profile](ARTIFACT-REVIEW.md) and [candidate history](ARTIFACT-REVIEW-VALIDATION.md).
The public usage skill is 1.3.0; the tracked package version remains 0.15.0.

Sol implemented the feature. Astra independently reproduced/fixed archive,
declaration, pointer, privacy, coverage and malformed-Markdown CPU issues, then
cleared the final implementation, documentation and bounded consumer decision.
Source checks: 62 focused regressions, 3,846 tests passed (three skipped), both
typechecks/build, coverage and negative-threshold probe. Coverage was 90.15%
statements, 86.64% branches, 87.20% functions and 91.92% lines. Real macOS
confinement dogfood passed against the candidate; this is not a fresh published
native-client or plugin-activation measurement.
